# 旧菜谱的数字核对（2026-10-02）

用第六、七轮同样的办法，让 Codex 把原有菜谱的用量和时间逐项对照各自引用的网页。引了网页来源的 376 道里完成了 33 批、约 260 道，其中 158 道列出了差异，共 1210 条。表在 `audit/`，只出表，没有据此改任何菜谱。提示词见 `../round6/dispatch-audit.sh`。

## 结论：这些表不能直接用来改稿

这个办法对“一道菜只有一个权威来源”的新菜谱有效，对旧菜谱基本无效：

- 1210 条差异里，823 条出在同时引了经典书的菜谱上。那些菜的用量本来就以书为准，网页只是骨架或佐证，和网页对不上是有意的。
- 372 条出在引了两个以上网页的菜谱上，绝大多数是“来源 A 和来源 B 互相不一致，本稿取了其中一个”。
- 只有 15 条出在单一网页来源的菜谱上（泰式烤鸡、金枪鱼酱小牛肉、冷吃兔）。逐条看过：泰式烤鸡是把鸡和腌料按来源的两倍、蘸汁按八分之一一致折算的，不是错；其余是时间写法的差别。

所以没有改稿。以后想查某一道旧菜谱，可以翻它对应的表看各来源怎么写。

没有核对的：引了网页但没排到的约 110 道（主要是改编自 HowToCook 的中餐），以及只引书、没有网页来源的 44 道。
