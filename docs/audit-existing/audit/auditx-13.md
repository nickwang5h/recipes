# 核对口径

核对对象为指定八篇的当前文本。各篇所列非 Health Canada 的 URL 均已打开，均返回可读的配料与步骤；没有“来源打不开，未核对”的篇目。未列 URL 的书籍不另找版本，Health Canada 熟度页按要求不核。

换算：1 cup＝240 ml，1 tbsp＝15 ml，1 tsp＝5 ml，1 oz＝28 g，1 lb＝454 g；面粉、生米、白糖每 cup 分别为 125 g、200 g、200 g。白糖 1 tbsp＝12.5 g，1 tsp＝25/6 g。来源同时给公制时优先使用公制。温度按 °C＝（°F－32）×5/9 换算。计数保留个、瓣、根、片，不编造单件重量；没有密度的食材不把 ml 当作 g。

配料表逐行区分“没有该配料”与“有食材、没有本稿对应数字或可用的单位换算”；后者在来源栏注明缺的是重量、体积或计数数字，不表示食材缺失。来源与本稿都未定量的同项记“一致”（仅表示均未定量）。时间表“来源没写，本稿是估计”按指定标签填写，只表示所核配方网页没有该数值；Health Canada 未核，不能据此判断熟度数值的其他依据。

差异百分比＝（本稿－按份数折算后的来源）÷折算后的来源。仅用来源明确的份数折算；没有份数的子配方不根据配料量倒推份数。范围以全范围报告；时间不随份数线性缩放。时间表核对本稿明确给出的时间或温度；来源另有分钟数而本稿只写状态的，注明该数值，不把缺省时间直接判为数字冲突。来源网页的不同配方、不同分支单独标明，不把另一道菜或明确未采用的分支算成本稿遗漏。
