## 核对口径

只核对这八篇 front matter 中有 URL 的来源；无 URL 的书籍未作网页核对。Health Canada 熟度页按要求免核。每篇的 URL 打开结果见下文；有打不开的来源，该篇整体标为“来源打不开，未核对”，两张表仅记录本稿数字，结论留空。

换算：1 cup＝240 ml，1 tbsp＝15 ml，1 tsp＝5 ml，1 oz＝28 g，1 lb＝454 g；面粉 1 cup＝125 g，白糖、生米 1 cup＝200 g。来源同时列公制时优先用该公制数，不用英制重新覆盖它。计数单位保留原计数，不虚构单个重量。百分比以来源折算值为分母。

来源没有明确份数时，不虚构份数。Penne 的 based.cooking 只给番茄／面条比例，按同样 320 g 面条核对这一比例；AVPN 只给每 1000 ml 水的面团配方，按本稿 235 ml 水列出比例换算，不能据此验证 servings。其余有份数的来源按份数折算。

配料确实存在、但来源仅写适量，或者给定换算表不足以把体积换成重量时，不能计算是否落在 15% 内：结论留空，并在数值栏说明缺失的依据；这不等于“来源没有这一项”。来源与本稿都没有定量、都按需或适量使用的同一配料记“一致（均未定量）”。时间与温度表也列出来源有而本稿未给数字的对应步骤，缺失数字记“不一致”，不计算虚假的百分比。
