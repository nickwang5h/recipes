# 第八轮：工作日能吃的菜（2026-10-28）

起因：站里有凑数的菜（糖拌西红柿、复热冷冻花卷），有不少要做三小时以上的菜，却缺家常主力菜；只勾“鸡翅”时冰箱页一道菜都找不出来。

这一轮做四件事：

1. 新增 60 道菜（`selection.json`、`batches.json`），偏向能带饭、一锅出和鸡翅，七个菜系都有。由 Codex 起草（`dispatch.sh`），审稿流程同第六、七轮（`../round6/REVIEW.md`）。
2. 菜谱加 `tags` 字段，给新旧菜谱都标上。
3. 菜谱加 `minor` 字段，用来给小菜和过于简单的做法降权：这些菜仍在列表里，但不出现在首页推荐和“今晚吃什么”里。不删任何菜。
4. 冰箱页：葱、姜、蒜算默认常备；一道菜也匹配不上时，放宽到差几样也列出来。

## 标签标准

- `bento`（能带饭）：做好后冷藏一到三天，第二天用微波炉复热，或者常温吃，口感变化不大。不能靠酥脆外皮、半熟的蛋或现做才好吃的酱汁，装盒后也不会出很多水。清炒绿叶菜、要趁刚出锅吃脆的炸物、汤面、刺身、半熟蛋都不算；炸好后浸在酱汁里的（南蛮鸡）可以算。
- `one-pot`（一锅出）：用一口锅、一个电饭煲或一个烤盘做完，成品里同时有主食、蛋白质和蔬菜，不用另配饭就是完整的一餐。只有肉和菜、需要另外配饭的不算；盖饭、丼这类另煮一锅饭再浇上去的也不算。炒面、炒粉前先煮一下面条的那锅水不算第二口锅。

## `minor` 标准

`minor: true` 给两类菜：一类是一两样材料拌一拌、蒸一蒸就成的小菜；另一类是复热半成品、一只蛋煮的蛋花这类不算一道菜的东西。正经的凉菜（拍黄瓜、口水鸡）和早餐粥不算。
