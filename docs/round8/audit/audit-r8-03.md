# 核对方法

来源原文列保留原配方数量；公制列为按本稿份数折算后的数。计数保留个、根、瓣；来源只给体积而本稿给重量时，不凭空设定密度。无法直接比较或来源未定量时标为“无法比较”，不推断一致。时间是过程时间，不按份数缩放。百分比以折算来源为分母。Health Canada 熟度及剩菜页按要求不核。
